## 4. 업무 로직 (VBA 역설계)

### 4.1 입력 (Sh1_Enter1~3)

검증 순서와 메시지를 그대로 이식할 대상입니다.

1. 일자 비었거나 날짜 아님 → "일자를 날짜형식('YYYY-MM-DD')으로 입력해 주세요."
2. 거래구분 비었음 → "거래구분을 선택해 주세요."
3. 금액 비었거나 숫자 아님 → "금액을 숫자형식으로 입력해 주세요."
4. 부가세가 있는데 숫자 아님 → "부가세를 숫자형식으로 입력해 주세요."
5. 합계금액 비었거나 숫자 아님 → "합계금액을 숫자형식으로 입력해 주세요."
6. 저장: 등록코드 발급 → 원장 마지막 행 추가 → 세액구분 기록 → 거래구분 자동 등록 → 대시보드 재계산

### 4.2 부가세 계산

- 세액구분 **별도(0)**: 부가세 = 금액 × 10% (원 미만은 통화형 변환으로 절사되어 저장됨, 예: 44,546 → 4,454)
- 세액구분 **없음(1)**: 부가세 = 0
- 합계 = 금액 + 부가세 (MAIN 입력 카드는 `=C9` 수식이라 별도 설정이어도 합계에 VAT가 안 더해지는 경우가 있음 → 5장 참조)

### 4.3 대시보드 집계 (Sh_Total)

| 블록 | 계산 |
|---|---|
| 연간 월별(M4:O16) | 선택 연도 × 월 × 종류별 **합계금액** 합 |
| 전년 비교(M21:O23) | 전년도 종류별 합계, 증감액, 증감률 |
| TOTAL(M25:O25) | 전체 기간 종류별 합계 |
| 일자별 현황(C22:I25) | 선택 일자의 종류별 금액·VAT·합계, 전일 대비 % |
| 분기 차트(Option!AJ2:AL5) | 월 집계를 3개월씩 합산 |

### 4.6 검색·현황

- **검색관리**: 기간(오늘/이번 달/올해 단축 버튼), 종류(전체/수입/비용/고정자산), 검색 필드(거래구분·내용·거래처·증빙·비고) + 검색어, **완전일치** 체크. 결과에서 수정·삭제·전체삭제·엑셀 저장.
- **거래별현황**: 종류 + 거래구분 + 증빙 + 기간.
- **거래처별현황**: 거래처 + 기간, 합계(건수·금액)와 누계.
- **월별현황**: 연도 + 종류(또는 전체) → 거래구분 × 1~12월 + 분기 소계 + 합계.
- **열 표시 설정(Sh_Chk)**: 검색 결과 열 12개 표시/숨김 체크.
- 모든 현황 시트: 미리보기·인쇄·새 통합문서로 내보내기.

## 5. 발견된 문제 (웹 이전 시 반드시 바로잡을 것)

| # | 심각도 | 문제 | 근거(2025년 데이터) | 웹 설계 대응 |
|---|---|---|---|---|
| 1 | **높음** | 사용자 추가 거래구분(한솔교재비, 공인인증수수료 등)이 명세서 어느 항목에도 매핑되지 않아 **필요경비에서 누락** | 비용 합계 32,064,420원 vs 부표 (41) 27,451,120원 → 차이 **4,613,300원**(한솔교재비 4,608,900 + 공인인증수수료 4,400) | 거래구분마다 `명세서 항목` 매핑을 필수로 저장, 미매핑 시 보고서에 경고 |
| 2 | **높음** | 계산서 (15)와 부표 (41)이 다름 | 계산서 26,551,120 / 부표 27,451,120 (900,000 차이) — 값 스냅샷이 서로 다른 시점 | 보고서는 저장하지 않고 요청 시 계산, 계산서는 부표 함수 결과를 직접 사용 |
| 3 | 중간 | 월별현황이 원장과 불일치 | 월별현황엔 "수강료" 행이 있으나 원장에선 이미 "매출"로 바뀜 | 동일 (요청 시 계산) |
| 4 | 중간 | 수입 구분 "수강료"가 부표 (11)·(12)에 반영되지 않음 | VBA는 "매출", "기타(수입)"만 집계 | 수입 구분도 매핑 필수 (수강료 → (11) 매출액) |
| 5 | 중간 | 금액+부가세 ≠ 합계인 행 존재 | A1206A(25,000+2,500≠25,000), A1234A(450,000+45,000≠450,000) | 서버에서 `합계 = 공급가액 + 부가세` 강제 |
| 6 | 낮음 | 일자별 "전일 대비"에서 비용·고정자산도 전일 **수입**합계와 비교 | Sh1_Today_2/3이 `Rng5(7)`(수입합계) 사용 | 같은 종류끼리 비교 |

> 1번은 실제 신고 금액에 영향을 줄 수 있는 문제입니다. 교재비를 어느 항목(예: 상품매입·소모품비·기타)으로 볼지는 세무 판단이 필요하므로, 웹 버전은 사용자가 매핑을 고르게 하고 기본값을 강요하지 않습니다. 세무사와 확인을 권합니다.
