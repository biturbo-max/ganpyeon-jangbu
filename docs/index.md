# 종합소득세 간편장부 웹앱

엑셀 매크로 간편장부를 **구글 시트 + Apps Script 웹앱**으로 옮긴 프로그램입니다.
데이터는 내 구글 드라이브에만 저장되고, 웹앱은 내 계정으로만 열립니다.

- [설치 방법 (README)](https://github.com/{{ site.github.repository_nwo }}#설치-처음-한-번-약-10분)
- [원본 엑셀 분석 보고서](01_분석보고서.md)
- [설계서 — 데이터·API·화면·출력양식](02_설계서_인터페이스_디자인.md)

## 할 수 있는 일

- 수입·비용·고정자산매입 입력 (부가세 별도/없음 자동 계산)
- 내역 검색·수정·삭제, CSV 저장
- 거래처 관리, 거래별·거래처별·월별 현황
- 총수입금액 및 필요경비명세서(별지 제82호서식 부표), 간편장부소득금액계산서(별지 제82호서식) A4 인쇄
- 명세서에 반영되지 않는 거래구분 경고
