# 종합소득세 간편장부 (Google Apps Script 웹앱)

엑셀 매크로(.xlsm)로 쓰던 간편장부를 구글 시트 + Apps Script 웹앱으로 옮긴 프로그램입니다.
수입·비용·고정자산 입력, 내역 검색·수정, 거래처 관리, 거래별·거래처별·월별 현황,
**총수입금액 및 필요경비명세서(별지 제82호서식 부표)** 와 **간편장부소득금액계산서(별지 제82호서식)** 인쇄를 지원합니다.

- 데이터는 **내 구글 드라이브의 스프레드시트**에만 저장됩니다.
- 웹앱은 **본인 구글 계정으로만** 열립니다(배포 설정 "액세스: 나만").
- 주민등록번호는 저장하지 않습니다.

> 이 프로그램은 장부 정리와 서식 작성을 돕는 도구입니다. 거래구분을 명세서 어느 항목에 넣을지 등 세무 판단은 세무사와 확인하세요.

## 구성

```
apps-script/
  Code.gs          화면 제공(doGet) + API(api) + 검증 + 시트 읽기/쓰기
  Reports.gs       부표·계산서·대시보드·현황 계산 (순수 함수)
  Index.html       화면 전체 (CSS·JS 포함 한 파일)
  appsscript.json  웹앱 배포 설정 (실행: 나, 액세스: 나만)
tools/migrate.py   기존 엑셀(.xlsm) → 구글 시트 가져오기용 .xlsx 변환
tests/             node tests/reports.test.js · node tests/api.test.js
docs/              분석 보고서 · 설계서
```

## 설치 (처음 한 번, 약 10분)

### 1. 기존 엑셀 데이터 변환 (기존 장부가 있을 때)

```bash
pip install openpyxl
python3 tools/migrate.py 원본장부.xlsm 장부데이터.xlsx
```

거래·거래처·거래구분·기본정보가 `transactions / partners / categories / settings / adjustments` 시트로 만들어집니다.
새로 시작한다면 이 단계를 건너뛰세요. 빈 스프레드시트에서 처음 실행할 때 시트가 자동으로 생깁니다(이때는 설정 화면에서 거래구분부터 추가).

### 2. 구글 스프레드시트 만들기

1. 구글 드라이브에 `장부데이터.xlsx` 업로드 → 우클릭 → **연결 앱 › Google 스프레드시트**로 열기
2. **파일 › Google 스프레드시트로 저장** (엑셀 형식 그대로면 스크립트를 붙일 수 없습니다)

### 3. Apps Script 붙이기

1. 스프레드시트 메뉴 **확장 프로그램 › Apps Script**
2. 기본 `Code.gs` 내용을 지우고 이 저장소의 `apps-script/Code.gs` 붙여넣기
3. **＋ › 스크립트** 로 `Reports` 추가 → `Reports.gs` 붙여넣기
4. **＋ › HTML** 로 `Index` 추가 → `Index.html` 붙여넣기
5. 왼쪽 ⚙ 프로젝트 설정 → "appsscript.json 매니페스트 파일 표시" 체크 → `appsscript.json` 내용 붙여넣기
6. 저장

(clasp를 쓰면: `cd apps-script && clasp clone <스크립트ID>` 후 `clasp push`)

> **구글 계정을 여러 개 로그인해 쓰는 경우** 확장 프로그램 › Apps Script가 "페이지를 찾을 수 없음"으로 열리지 않을 수 있습니다.
> 그때는 `script.google.com/u/1/`(두 번째 계정이면 1)에서 **새 프로젝트**를 만들고 위 파일을 붙여넣은 뒤,
> `Code.gs` 맨 위 `SHEET_ID`에 장부 스프레드시트 ID(주소의 `/d/`와 `/edit` 사이)를 넣으면 됩니다.

### 4. 웹앱 배포

1. 오른쪽 위 **배포 › 새 배포 › 유형: 웹 앱**
2. 실행 사용자: **나**, 액세스 권한: **나만** → 배포
3. 권한 승인(이 스프레드시트에만 접근) 후 나오는 **웹 앱 URL**을 즐겨찾기

> **"현재 파일을 열 수 없습니다"가 뜰 때** — 크롬에 구글 계정이 여러 개 로그인되어 있으면 Apps Script 웹앱은
> **첫 번째(기본) 계정**으로만 열립니다(구글 쪽 제한, 주소에 `/u/1/`이나 `authuser`를 붙여도 해결되지 않음).
> 해결: ① 장부 계정만 로그인한 **크롬 프로필**을 따로 만들어 그 프로필에서 웹앱 주소를 즐겨찾기 하거나,
> ② 모든 계정에서 로그아웃한 뒤 장부 계정으로 **가장 먼저** 로그인하세요. 시크릿 창에서 장부 계정만 로그인해도 열립니다.

코드를 바꾼 뒤에는 **배포 › 배포 관리 › 수정 › 버전: 새 버전**으로 다시 배포해야 반영됩니다.

### 5. 처음 열었을 때 할 일

1. **설정 › 기본정보** 확인 (서식 머리에 들어갑니다)
2. **설정 › 거래구분**에서 빨간 테두리(미지정) 항목의 **명세서 반영 항목**을 지정
   — 지정하지 않은 거래구분은 명세서에서 빠지고 대시보드에 경고가 뜹니다.

## 기존 엑셀과 달라진 점

| 기존 | 지금 |
|---|---|
| 직접 추가한 거래구분은 명세서에서 조용히 빠짐 | 거래구분마다 명세서 항목 지정, 미지정은 경고 |
| 계산서·명세서·월별현황이 매크로 실행 시점 값으로 남아 서로 어긋날 수 있음 | 열 때마다 원장에서 새로 계산 |
| "수강료"가 명세서 매출액에 안 들어감 | 수강료 → (11) 매출액 |
| 금액+부가세 ≠ 합계인 행이 생길 수 있음 | 합계는 항상 서버가 계산 |
| 일자별 전일 대비가 비용도 전일 수입과 비교 | 같은 종류끼리 비교 |
| 수입금액/비용금액/고정자산금액 9열 | 공급가액·부가세·합계 3열 + 거래종류 |

## 테스트

```bash
node tests/reports.test.js   # 계산 로직
node tests/api.test.js       # API (구글 시트를 메모리로 흉내)
```

원본 엑셀 2025년 데이터로 검증한 값: 수입금액 합계(13) 30,041,009원, 필요경비(41) 27,451,120원(미지정 항목 제외 시),
월별·전년비교·전체 누계 모두 원본 대시보드와 일치.
